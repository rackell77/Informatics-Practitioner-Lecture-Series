# Informatics Practitioner Lecture Series 2026 - Task & Case Studies

Repository ini berisi ringkasan materi, studi kasus, serta implementasi kode program Java untuk rangkaian kegiatan **Informatics Practitioner Lecture Series 2026**.

---

## 📌 Ringkasan Sesi & Studi Kasus

### **Sesi 1: Make Sense of Data with Analysis and AI**
* **Studi Kasus:** Prediksi Risiko Keterlambatan Pembayaran Invoice (*Invoice Late Payment Risk*).
* **Deskripsi:** Mengklasifikasikan invoice pelanggan berdasarkan riwayat keterlambatan dan skor kredit untuk membantu tim keuangan mengidentifikasi risiko lebih awal.
* **Implementasi Kode:** `Sesi_1/Sesi1_LatePaymentRisk.java`

### **Sesi 2: Bridging Global Infrastructure to Address Local Challenges with HPC**
* **Studi Kasus:** Simulasi Pemrosesan Data Paralel Berbasis *Multithreading*.
* **Deskripsi:** Membandingkan waktu eksekusi sekuensial vs *multithreading* (simulasi pemrosesan node mini-HPC) untuk komputasi beban tinggi.
* **Implementasi Kode:** `Sesi_2/Sesi2_HPCParallelProcessing.java`

### **Sesi 3: Career and Competition in Industrial Era with GIS**
* **Studi Kasus:** Perhitungan Jarak Geospasial & Penentuan Zona Buffer.
* **Deskripsi:** Menghitung jarak antara koordinat lokasi aset dengan titik pusat menggunakan Formula Haversine untuk analisis jangkauan GIS.
* **Implementasi Kode:** `Sesi_3/Sesi3_GISDistanceCalculator.java`

### **Sesi 4: Introduction to Machine Learning**
* **Studi Kasus:** Klasifikasi Data Menggunakan Algoritma *K-Nearest Neighbors (KNN)*.
* **Deskripsi:** Mengklasifikasikan sampel data baru berdasarkan perhitungan jarak Euclidean terdekat dari data latih.
* **Implementasi Kode:** `Sesi_4/Sesi4_SimpleKNN.java`

### **Sesi 5: Human-Computer Interaction & Data Visualization**
* **Studi Kasus:** Dashboard Visualisasi Data Berbasis Teks (*Text-based Dashboard*).
* **Deskripsi:** Menampilkan indikator energi dengan elemen visual sederhana (*Preattentive Visual Attributes*) untuk meminimalkan beban kognitif pengguna.
* **Implementasi Kode:** `Sesi_5/Sesi5_HCIDashboardInterface.java`

### **Sesi 6: Attributing Direct Drivers to Deforestation Alerts with Satellite Imagery and AI**
* **Studi Kasus:** Atribusi Penyebab Deforestasi Berdasarkan Indeks Spektral Satelit.
* **Deskripsi:** Memprediksi pemicu utama kerusakan hutan (pertambangan, pertanian, perambahan) berdasarkan nilai spektral NDVI & NDBI dari citra satelit.
* **Implementasi Kode:** `Sesi_6/Sesi6_DeforestationDriverClassifier.java`
